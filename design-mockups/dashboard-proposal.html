Static mockup — no application code was touched. Toggle dark mode to check both themes.

Where each pattern comes from

Real screens from shipped products (via Mobbin), matched to the blocks above. The goal isn't to copy any one product — it's to borrow proven answers for "how should a fleet/security dashboard communicate?"

Cloudflare 1
Account overview: status-first hierarchy and a short "things that need you" list. The model for the Needs-attention table.
View on Mobbin →
Vanta 2
The security-posture gold standard: one big score gauge, then checks broken down by pass rate. Maps 1:1 to Plugsent's score + 14 checks.
View on Mobbin →
Google Analytics 3
The classic KPI row — big number, one-line context, comparison delta. Nothing communicates fleet status faster at a glance.
View on Mobbin →
Amplitude 4
Compact trend sparklines inside stat cards — "is this number getting better or worse?" without a full chart.
View on Mobbin →
Better Stack 5
Per-monitor 30-day bar strips with a colour legend — the same pattern as Plugsent's existing site uptime strip, promoted to fleet level.
View on Mobbin →
Tailscale 6
Restrained infra admin: quiet table, clear status dots, no decoration. Confirms the Sites table just needs polish, not replacement.
View on Mobbin →
incident.io 7
Scannable event timeline with severity colouring — the pattern for surfacing SiteCommand / UpdateRun history fleet-wide.
View on Mobbin →
1Password 8
Watchtower-style pass/fail check summary with friendly, non-alarming copy — the tone for the fleet checks list.
View on Mobbin →
Railway 9
Resource header done right: name, status and actions in one strip, tabs right below. The model for the site detail header and its seven tabs.
View on Mobbin →
Vercel 10
Dense project-overview metrics cards that still feel calm — the model for the upgraded Security / Updates / Uptime category cards.
View on Mobbin →

Sample data, real vocabulary. Scores, updates, vulnerabilities and uptime above are invented but consistent (12 sites, avg score 80, 44 pending updates, 16 open vulnerabilities). The 14 security checks are Plugsent's actual checks from app/Actions/EvaluateSiteSecurity.php; site fields match app/Models/Site.php.

Scope if we build it: the dashboard is new Filament v5 widgets; the Sites list is column + grouping tweaks to the existing table; the site overview restyles the category cards you already render. All styled with the existing plugsent.css vocabulary — no new dependency, no chart library (bars and rings are CSS/SVG). Every other page stays untouched.

References: thumbnails downloaded from Mobbin (links above; image URLs expire after ~30 days). Brand font loaded from the panel's own self-hosted file — keep this file inside the repo for full fidelity.
