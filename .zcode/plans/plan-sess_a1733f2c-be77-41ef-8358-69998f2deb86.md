# Email templates, Profile & password management, 2FA, password eye icons

## 1. Branded email template system
- New `resources/views/mail/plugsent.blade.php` — a branded HTML email layout (Plugsent header, colored status banner slot, content, footer) following the existing `mail/workspace-invitation.blade.php` pattern.
- Four email types built on it:
  1. **Uptime alerts** — rework `SiteDownNotification` / `SiteRecoveredNotification` to render the branded template (red "Site down" / green "Recovered", site, URL, time, error/status code, dashboard button).
  2. **Security alerts** — sent to workspace owner/admins when a site's vulnerability count **increases**, throttled to at most one email per site per day: affected plugins/themes with counts, "fix available" hints, link to the site's Security tab.
  3. **Updates available — daily digest** — a scheduled once-a-day email per workspace listing every site with pending updates (site name, item names, versions), with links to each site's Plugins tab. No emails for individual updates. Skipped silently for workspaces with nothing pending. Respects each user's email preference (see §2).
  4. **Password mails** — password reset keeps Filament's built-in flow; add a branded **"Your password was changed"** notification sent whenever a user's password changes (profile update or reset), with a "this wasn't you" line.

## 2. Profile page (per-user)
New Filament page `app/Filament/Pages/Profile.php` + view (modeled on the existing Settings page), navigation "My account":
- **Profile** section: update name + email (uniqueness-checked).
- **Password** section: current password + new password + confirmation; signs out other browser sessions.
- **Email preferences**: opt in/out of uptime alerts, security alerts, and the daily updates digest (JSON pref on the user, checked by all senders).

## 3. Two-factor authentication (TOTP)
- Composer: `pragmarx/google2fa` + `chillerlan/php-qrcode` (pure PHP, no extensions).
- Migration: `two_factor_secret` (encrypted), `two_factor_recovery_codes` (hashed JSON), `two_factor_confirmed_at` on users.
- **Setup in Profile**: Enable 2FA → QR + secret → confirm with a 6-digit code → 8 one-time recovery codes shown once. Disable requires the current password.
- **Login challenge**: custom Login page — after valid credentials, 2FA users get a code step (TOTP or a recovery code, consumed on use). Recovery codes stored hashed.

## 4. Eye icons on every password field
Filament's `->revealable()` on all password inputs: custom Register page, new custom Login + password-reset pages, the invite-join page, and the Profile password fields.
